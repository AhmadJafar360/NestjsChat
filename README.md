## Deskripsi

Aplikasi Chatting menggunakan **Nestjs** dan **React**.

## Instalasi

```bash
# Menginstall dependencies
$ npm install
```

## Jalan Aplikasi

```bash
# Buka mongodb dan connect ke database anda
- Contoh url: mongodb://localhost:27017/nama_database

# Jalankan server Backend
$ cd backend
$ npm run start:dev

# Jalankan frontend
$ cd frontend
$ npm start
```
